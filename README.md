# 酷飞云安装包

此仓库只发布酷飞云的安装包、版本说明和 Android 自动更新清单，不存放应用源码。

- [下载最新版本](https://github.com/meYesWho/fei-music-releases/releases/latest)
- Android 安装包名称：`app-release.apk`（ARM64，Android 8.0 及以上）。
- `update.json` 供应用检查新版本；只有 APK 构建和上传成功后才发布该清单。
- Windows / iOS 仅在对应平台构建成功时提供附件；iOS 包如标注未签名，需要后续签名。

更新需要确认系统安装提示。APK 的应用包名和签名应与已安装版本一致。
